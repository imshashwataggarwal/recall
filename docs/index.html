What is Recall?

Agentic CLIs are brilliant in a session and amnesiac between them. Recall is the memory layer that fixes that — a small, local tool that captures decisions, fixes, and context as you work, then retrieves the most relevant pieces the moment a new session needs them.

📝

Markdown is the source of truth

Every memory is an append-only, timestamped entry in a human-readable Markdown file under ~/.recall. The SQLite index is just a rebuildable cache.

🔍

Hybrid retrieval

FTS5 BM25 keyword search fused with sqlite-vec semantic vectors via Reciprocal Rank Fusion, with recency decay — so it finds the right thing even with zero word overlap.

🔒

Fully local & private

Embeddings run on local Ollama. No cloud, no API keys, no telemetry. Degrades gracefully to keyword-only if optional pieces aren’t installed.

♻️

Self-evolving

A consolidation loop distills raw entries into durable per-workstream summaries and a catalog, so memory gets more useful over time, not noisier.

How it works

Recall plugs into your agent two ways: as a set of MCP tools the agent calls directly, and as a session-end hook that captures what just happened. Both read and write the same local store.

~/.recall/sessions)] M --> I[Indexer] I --> D[(SQLite
FTS5 + sqlite-vec)] F --> D E[Ollama
embeddinggemma] -. embeddings .-> I E -. query vector .-> F F -->|ranked context| A
1

Capture

The agent (or the hook) appends an atomic entry to a Markdown workstream file — never overwriting history.

2

Index

Changed entries are chunked and embedded locally, then written incrementally to the SQLite BM25 + vector index.

3

Retrieve

A query runs keyword + semantic search, fuses the rankings, decays by age, and returns cited context.

4

Consolidate

Periodically, raw entries are distilled into durable summaries — the loop that keeps memory sharp.

Why it’s nice to live with

⚡

Zero-config start

One install command sets up the CLI, the recall-mcp server, and (optionally) pulls a local embedding model.

🧩

Agent-agnostic

Works with Copilot CLI out of the box and any MCP-capable agent. An AGENTS.md ships in the repo.

🛡️

Never breaks your shutdown

The session-end hook is fail-safe: bad input or a missing index just exits cleanly, never blocking the agent.

🧳

Portable memory

Your knowledge lives in a folder. git init it or sync it across machines — the index rebuilds itself.

🧪

Tested & offline-friendly

A full pytest suite runs without a network using a fake embedder. CI included.

📖

Documented

Architecture, design, call-flows, configuration and CLI reference — all in /docs.

Get started

Pick whichever fits your setup. All three give you the recall and recall-mcp commands.

curl -fsSL https://raw.githubusercontent.com/imshashwataggarwal/recall/main/scripts/install.sh | bash
irm https://raw.githubusercontent.com/imshashwataggarwal/recall/main/scripts/install.ps1 | iex
pipx install "git+https://github.com/imshashwataggarwal/recall.git#egg=recall[mcp]"

Then point your agent at the MCP server and you’re done. Full setup & wiring: installation guide · MCP & Copilot integration.
